# 🚀 Hossam Hesham — Portfolio

A modern, interactive portfolio website showcasing my work as a **Flutter Developer & Mobile Architect**. Built with vanilla HTML, CSS, and JavaScript, featuring smooth animations, particle effects, and a responsive design.

## ✨ Features

- **Modern Design** — Dark theme with cyan and purple accent colors, custom typography
- **Interactive Animations** — Particle canvas, smooth scroll animations, reveal effects
- **Custom Cursor** — Unique cursor experience with custom dot and ring
- **Smooth Loader** — Animated page loader with initials and loading bar
- **Responsive Layout** — Mobile-first design that works on all devices
- **Smooth Navigation** — Sticky navbar with smooth scrolling to sections
- **Sections Include**:
  - Hero section with availability status
  - Skills showcase with progress bars
  - Professional experience
  - Project portfolio
  - Education background
  - Contact information

## 🛠️ Tech Stack

**Frontend:**
- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- Vanilla JavaScript (ES6+)
- Google Fonts (Syne, DM Sans)

**Design Features:**
- Canvas API for particle effects
- CSS animations and transitions
- Responsive viewport meta tags

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/HossamHesham2/HossamHesham2.github.io.git
   cd HossamHesham2.github.io
   ```

2. **Open in browser:**
   - Simply open `index.html` in your web browser
   - Or use a local server for best results:
     ```bash
     python -m http.server 8000
     # Then visit http://localhost:8000
     ```

3. **View online:**
   - Visit: https://HossamHesham2.github.io

## 🎨 Customization

### Colors
Modify the CSS variables in `style.css`:
```css
:root {
    --gold: #00F2FE;           /* Primary color */
    --gold-light: #4FACFE;     /* Light variant */
    --gold-dark: #0061FF;      /* Dark variant */
    --accent: #7000FF;         /* Accent color */
    --bg: #020617;             /* Background */
    --text: #F1F5F9;           /* Text color */
}
```

### Content
Edit `index.html` to update:
- Personal information in the hero section
- Skills data in `main.js` (SKILLS array)
- Experience, projects, and education content
- Profile image in `images/` folder

### Animations
Adjust animation timings and effects in:
- CSS: `style.css` (keyframes and transitions)
- JavaScript: `main.js` (animation triggers and particle effects)
